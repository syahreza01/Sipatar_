NOTIFIKASI EKSTERNAL

Telegram Bot

Siapkan kanal notifikasi untuk peringatan SIPATAR.

BELUM DIUJI

Konfigurasi bot

Token yang dimasukkan di sini hanya dipakai untuk pesan uji, tidak disimpan di browser.

Untuk notifikasi otomatis, isi token dan Chat ID di firmware/esp8266_sensor/include/local_config.h, aktifkan TELEGRAM_ENABLED, lalu unggah ulang ESP8266. Jangan bagikan token bot.

Aturan notifikasi

Atur notifikasi ESP8266 dengan TELEGRAM_NOTIFY_* di local_config.h. Notifikasi offline perlu pemantau cloud.

Log notifikasi

Ambang sensor dashboard

Dipakai untuk menilai status dan peringatan pada data simulasi maupun data perangkat nyata.

Flame sensor hanya mendeteksi api, bukan suhu. Untuk ambang °C, gunakan sensor suhu DHT22. Pengaturan ini mengubah peringatan dashboard saja; ambang buzzer/LED pada ESP8266 masih diatur terpisah di firmware.

Data dan sesi

Kontrol data demonstrasi pada browser.

Pengaturan disimpan pada localStorage browser. Menghapus data situs dapat menghapus pengaturan ini.
